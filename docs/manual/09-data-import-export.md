# 9부. 데이터 가져오기·내보내기

성격이 다른 네 가지 기능이 있다. 먼저 구분부터 한다.

| 기능 | 어디서 | 무엇을 하나 |
| --- | --- | --- |
| 엑셀 워크시트 가져오기 | 프로젝트의 "가져오기" 탭 | 엑셀 워크북을 읽어 **워크시트 11 종에 반영**한다 |
| 사업계획 양식 | 프로젝트 개요 편집 | 엑셀 양식을 읽어 **개요 세 칸을 채운다** |
| 데이터 내보내기 | 프로젝트 설정 → 데이터 관리 | 프로젝트를 **JSON 으로 백업**한다 |
| 데이터 가져오기 | 프로젝트 설정 → 데이터 관리 | 백업한 JSON 을 **복원**한다 |

엑셀 가져오기와 JSON 가져오기는 이름이 비슷하지만 용도가 전혀 다르다. 원본 워크시트를
옮겨 오는 것은 엑셀 쪽이고, 백업 복원은 JSON 쪽이다.

## 9.1 엑셀 워크시트 가져오기

프로젝트 개요 화면의 "가져오기" 탭으로 들어간다. 이 탭은 **편집 권한자에게만**
보인다. 안에서 "업로드 페이지로 이동" 을 누르면 전용 화면이 열린다.

화면 제목은 "엑셀 워크시트 가져오기", 부제는 "전체 워크북 또는 선택 워크시트를
분석하고 프로젝트 데이터로 반영합니다." 다.

### 순서

1. **업로드 양식을 받는다.** "업로드 양식 다운로드" 버튼으로 받는다.
2. **파일을 고른다.** `.xlsx` 와 `.xls` 만 되고 최대 10MB 다. 드래그해도 된다.
3. **업로드 방식을 정한다.** "전체 워크북" 은 인식 가능한 모든 시트를 처리하고,
   "워크시트 선택" 은 쉼표로 적은 시트만 처리한다.
4. **시스템 반영 방식을 정한다.** "기존 값 교체" 는 해당 워크시트의 기존 데이터를
   새 값으로 바꾸고, "기존 값에 추가" 는 뒤에 덧붙인다.
5. **"엑셀 분석" 을 누른다.** 이 단계에서는 아직 아무것도 반영되지 않는다.
6. **결과를 확인한다.**
7. **"분석 결과를 시스템에 반영" 을 누른다.**

**분석과 반영이 나뉘어 있다.** 분석만 하고 그만둬도 데이터는 바뀌지 않는다.

### 분석 결과 읽는 법

- **분석 요약** 카드에 전체 시트, 선택 시트, 인식 시트, 상태가 나온다.
- **경고와 오류**가 목록으로 나온다. 경고는 최대 여덟 개까지만 보여 준다.
- **반영 대상 데이터**에 어느 워크시트에 몇 건이 들어가는지 나온다.
- **시트별 카드**에 행·열 수와 값·수식 개수, 그리고 표 미리보기가 나온다. 미리보기는
  8 행 8 열까지다.

### 깨진 수식이 있으면 막힌다

엑셀에 `#REF!` 같은 깨진 수식이 있으면 반영 버튼이 눌리지 않고 어디가 문제인지
시트와 셀 위치가 표시된다.

> 깨진 수식이 있어 시스템 반영 전에 수정이 필요합니다.

엑셀에서 고쳐서 다시 올린다.

### 함께 지워지는 데이터 경고

고객요구사항을 "기존 값 교체" 로 덮어쓰면 그에 딸린 것들이 함께 사라진다. 그런
경우 반영 직전에 확인 창이 한 번 더 뜬다.

> 고객요구사항을 덮어쓰면 Kano 설문 응답 N건, 벤치마크 N건, QFD 관계 N건이 함께
> 삭제됩니다. 설문 응답은 다시 모을 수 없습니다.

**설문 응답은 되돌릴 수 없다.** 취소하면 "반영을 취소했습니다. 기존 데이터는 그대로
유지됩니다." 가 뜨고 아무것도 바뀌지 않는다.

### 권장 워크시트

화면 아래 "권장 워크시트" 카드의 버튼을 누르면 그 이름이 선택 목록에 쌓인다. 열한
개가 있다.

자사매출추정표, AS-IS스펙표, 제품속성표, 고객요구사항도출표, QFD, 개선포인트도출,
최종목표스펙도출, 향후목표고객LIST, 핵심자산과 보완자산표, 자금소요계획표,
자금조달계획표.

시트 이름이 조금 달라도 인식하는 경우가 있다. 예를 들어 AS-IS스펙표는 "AS-IS 스펙표",
"ASIS스펙", "스펙표" 도 같은 것으로 본다.

### 자주 나오는 오류

| 문구 | 원인 |
| --- | --- |
| .xlsx 또는 .xls 파일만 업로드할 수 있습니다. | 형식이 다르다 |
| 파일 크기는 10MB를 초과할 수 없습니다. | 용량 초과다 |
| 요청한 워크시트를 찾을 수 없습니다. | 시트 이름이 다르다. 화면에 있는 시트 목록을 확인한다 |
| 엑셀 파일을 분석하지 못했습니다. | 파일이 깨졌을 수 있다 |
| 지원하지 않는 워크시트 "..."는 건너뜁니다. | 인식 목록에 없는 시트다 |
| 워크시트 "..."에서 반영할 값을 찾지 못했습니다. | 시트는 찾았으나 값이 비었다 |

일부 워크시트 화면(WS-2, WS-3, WS-5)에는 그 워크시트만 올리는 업로드 버튼이 따로
있다. 사용법은 [7부](07-worksheets.md)의 각 절에 있다.

## 9.2 가져오기 이력

엑셀 반영이 성공하면 이력이 기록된다. **다만 이 이력을 보여 주는 화면은 없다.**
사용자에게 보이는 곳은 관리자가 회원을 지울 때의 확인 문구 한 곳뿐이다.

> 엑셀 가져오기 N건은 남고 가져온 사람만 비워집니다.

무엇을 언제 올렸는지 확인하려면 워크시트 내용을 직접 본다.

## 9.3 사업계획 양식으로 개요 채우기

프로젝트 개요의 제품개요를 손으로 채우는 대신 엑셀 양식으로 한 번에 넣을 수 있다.

1. 개요 화면에서 "수정" 을 눌러 편집 모드로 들어간다.
2. **"양식 다운로드"** 를 누른다. `사업계획_입력양식.xlsx` 가 받아지며 프로젝트명이
   미리 채워져 있다.
3. 양식의 **[내용] 칸에만** 적는다. 항목 이름은 바꾸지 않는다.
4. "사업계획 파일" 에 그 엑셀을 올린다.
5. 칸이 자동으로 채워지면 확인하고 **"저장"** 을 누른다.

양식에 있는 항목은 다섯 개다.

| 항목 | 작성 도움말 |
| --- | --- |
| 프로젝트명 | 워크시트 상단과 목록에 표시될 이름입니다. |
| 간단 설명 | 제품·서비스를 한두 문장으로 요약하세요. |
| 고객 정의 | 누가 쓰는 제품인지 대상 고객을 구체적으로 적으세요. |
| 고객 문제 정의 | 그 고객이 겪는 문제와 불편을 적으세요. |
| 핵심기능 | 문제를 푸는 핵심기능을 줄바꿈으로 나열하세요. WS-2 작성에 그대로 쓰입니다. |

양식에는 "작성안내" 시트가 함께 들어 있다.

읽어 들이면 "양식에서 ... 항목을 불러왔습니다. 확인 후 저장하세요." 가 뜬다.
**불러오기만 한 상태이므로 저장을 눌러야 반영된다.** 비어 있는 항목은 건너뛰므로 이미
적은 내용이 지워지지 않는다.

| 문구 | 원인 |
| --- | --- |
| 양식에서 읽을 수 있는 항목이 없습니다. [내용] 칸에 입력했는지 확인하세요. | 내용 칸이 비었다 |
| 사업계획 양식을 읽지 못했습니다. 첨부는 그대로 유지됩니다. | 양식이 아니거나 깨졌다. 파일 첨부 자체는 남는다 |

엑셀이 아닌 파일(PDF, DOC 등)을 올리면 첨부만 되고 자동 채우기는 일어나지 않는다.

## 9.4 데이터 내보내기

프로젝트 설정의 "데이터 관리" 탭에서 한다.

> 프로젝트의 모든 데이터를 JSON 파일로 다운로드합니다. 백업이나 다른 환경으로 이전
> 시 사용하세요.

포함되는 것은 이렇게 안내된다.

- 프로젝트 정보
- AS-IS 스펙표 (FAST 분석)
- 제품 속성 및 적합도
- 고객 요구사항
- 기술특성 및 QFD 매트릭스
- Kano 설문 응답

"JSON 파일로 내보내기" 를 누르면 `{프로젝트명}_{날짜}.json` 이 받아진다.

> **주의.** 내보낸 파일에는 프로젝트 내용과 설문 응답이 그대로 들어 있다. 공유하거나
> 보관할 때 다루는 데 주의한다.

**프로젝트를 지우기 전에는 반드시 먼저 내보낸다.** 프로젝트 삭제는 되돌릴 수 없다.

## 9.5 데이터 가져오기(복원)

같은 탭의 아래쪽이다.

> 이전에 내보낸 JSON 파일을 업로드하여 데이터를 복원합니다.

화면의 주의사항이 셋이다.

- 기존 데이터가 모두 덮어씌워집니다
- 이 작업은 되돌릴 수 없습니다
- 먼저 현재 데이터를 백업하는 것을 권장합니다

`.json` 파일을 고르고 "데이터 가져오기" 를 누른다. 파일에 실제로 들어 있는 항목만
지우고 다시 넣는다. 항목 사이의 연결은 알아서 다시 이어 준다.

고객요구사항이 바뀌는 경우에는 엑셀 가져오기와 같은 확인 창이 뜬다. 취소하면 "가져오기를
취소했습니다. 기존 데이터는 그대로 유지됩니다." 가 나온다.

성공하면 항목별 건수가 알림 창에 나오고 **화면이 자동으로 새로 고쳐진다.**

## 9.6 어느 것을 쓸지 고르는 법

| 하려는 일 | 쓸 기능 |
| --- | --- |
| 기존 엑셀 워크북의 내용을 옮겨 오고 싶다 | 엑셀 워크시트 가져오기 |
| 개요만 빨리 채우고 싶다 | 사업계획 양식 |
| 지우기 전에 남겨 두고 싶다 | 데이터 내보내기 |
| 백업을 되돌리고 싶다 | 데이터 가져오기 |
| 한 워크시트만 올리고 싶다 | 그 워크시트 화면의 업로드 버튼 |

어느 쪽이든 **덮어쓰기 전에 확인 문구를 끝까지 읽는다.** 특히 Kano 설문 응답은 한 번
지우면 다시 모을 수 없다.
