# 8부. 결과보고서

워크시트의 결과와 멘토 분석을 모아 Word 문서로 만드는 화면이다. 주소는
`/project/{프로젝트ID}/report` 이며 프로젝트 개요 화면의 "결과보고서" 버튼으로
들어간다.

## 8.1 누가 무엇을 할 수 있나

| 사람 | 할 수 있는 일 |
| --- | --- |
| 배정된 멘토 | 작성, 미리보기 생성, 초안 저장, 완료, 내려받기 |
| 관리자 | 초안 열람과 내려받기 |
| 멘티와 팀원 | **완료된 보고서만** 열람과 내려받기 |

화면 위쪽 설명이 지금 상태를 알려 준다.

- 멘티가 보면 "배정 멘토가 작성하고 완료하면 멘티에게 공개됩니다."
- 관리자가 보면 "저장된 초안을 열람하고 있습니다. 배정 멘토만 작성·완료할 수 있습니다."
- 완료본을 보고 있으면 "멘토가 완료한 결과보고서입니다."

아직 완료된 것이 없으면 "아직 완료된 결과보고서가 없습니다. 멘토가 완료하면 이
화면에서 열람할 수 있습니다." 가 뜬다.

## 8.2 보고서가 값을 가져오는 곳

보고서는 세 군데에서 내용을 끌어온다.

| 원본 | 들어가는 곳 |
| --- | --- |
| 프로젝트 개요의 제품 정보 | 제품명, 제품설명, 제품 이미지, 시장정의, 목표고객 |
| 여덟 개 워크시트의 멘토 분석 | 각 절의 분석 글 |
| 워크시트 표와 화면 | 표 내용과 그림 세 장 |

화면의 "보고서 원본 연결" 카드에도 같은 내용이 적혀 있다.

> 제품 정보는 개요에서, 분석은 각 워크시트의 '멘토 분석(보고)'에서 불러옵니다. 아래
> 보완 입력은 연결된 원본이 없는 항목에만 사용됩니다.

### 그림으로 들어가는 세 화면

다음 세 화면은 **표가 아니라 그림으로** 문서에 들어간다.

| 워크시트 | 문서에서의 이름 |
| --- | --- |
| WS-4 제품속성적합도 | 제품/서비스 속성 적합도 |
| WS-7 TIMKO/만족계수 그래프 | Kano 2D 산점도 |
| WS-9 QFD | 고객수요기반 기술스펙 관계도 |

화면 아래쪽에 이 세 워크시트가 읽기 전용으로 깔린다. 안내는 이렇다.

> 아래 워크시트는 읽기 전용이며 문서의 그림으로 저장됩니다. 값이 표시된 뒤 미리보기를
> 만들어 주세요.

**값이 다 뜨기 전에 미리보기를 만들면 그림이 비어서 들어간다.** 화면이 다 그려진
것을 확인하고 누른다. Kano 응답이 없으면 "Kano 응답이 없어 산점도를 그릴 수
없습니다." 가 그 자리에 표시된다.

### 보완 입력

원본이 없는 항목만 직접 적는 칸이 나온다. 조건은 이렇다.

| 칸 | 나오는 조건 |
| --- | --- |
| 시장정의 | 개요에 값이 없을 때 |
| 목표고객 | 개요에 값이 없을 때 |
| 최종 목표 스펙 항목별 설명 | WS-12 멘토 분석이 없을 때 |
| 개선 제품(서비스)명 | WS-13 멘토 분석이 없을 때 |
| 개선 제품설명 | WS-13 멘토 분석이 없을 때 |
| 제품/서비스 이미지 | 개요에 제품 정보가 없을 때. 20MB 이하 |

**원본을 채우는 쪽이 낫다.** 보완 입력은 보고서에만 남고 워크시트로 돌아가지 않는다.

## 8.3 문서 구성

만들어지는 Word 문서는 다섯 장으로 되어 있다.

| 장 | 주요 내용 |
| --- | --- |
| 표지 | KS-QFD 결과보고서, 기업명, 작성일, 코치명 |
| Ⅰ. 제품/서비스 개요 | 제품명과 설명, 제품 이미지, 시장정의, 목표고객, 매출 현황과 목표 |
| Ⅱ. 제품/서비스 속성 분석 | AS-IS 스펙표, 제품속성서, 적합도 그림과 각 멘토 분석 |
| Ⅲ. 고객수요 및 기술 분석 | 고객요구사항, Kano 집계표와 산점도, QFD 관계도, 개선 기능 목록 |
| Ⅳ. 최종 개선 방향 | 최종 목표 스펙, 핵심·보완자산과 각 멘토 분석, 개선 방향성 |
| Ⅴ. 자금 계획 | 자금소요계획표, 자금조달계획표와 각 멘토 분석 |

값이 없는 표에는 "입력된 데이터가 없습니다" 가, 그림을 만들지 못한 자리에는 "그림을
캡처하지 못했습니다" 가 들어간다.

내려받는 파일 이름은 `결과보고서_{프로젝트명}.docx` 다.

## 8.4 작성 절차

### 1단계. 멘토 분석을 먼저 쓴다

여덟 개 워크시트에 분석을 쓰고 저장한다. [6.2](06-mentor.md#62-멘토-분석보고-작성)를
본다. **저장만으로는 보고서에 들어가지 않는다.**

### 2단계. 미리보기를 만든다

결과보고서 화면에서 "미리보기 만들기" 를 누른다. 이미 초안이 있으면 "미리보기 다시
만들기" 로 바뀌고 확인 창을 한 번 거친다.

> 최신 워크시트와 위 입력 항목으로 문서를 다시 만듭니다. 현재 미리보기에서 직접
> 교정한 내용은 교체됩니다. 기존 공개본은 그대로 유지됩니다.

**다시 만들면 손으로 고친 내용이 사라진다.** 교정을 많이 했다면 순서를 생각해서
누른다.

진행 상황이 한 줄로 표시된다. "0/3 캡처 중..." 부터 "문서 만드는 중..." 까지다.
워크시트를 불러오는 동안에는 "워크시트 불러오는 중 N/11" 이 나온다.

만들지 못하는 경우와 이유는 이렇다.

| 문구 | 원인과 조치 |
| --- | --- |
| 워크시트 N개를 불러오지 못해 새 문서를 만들 수 없습니다. 저장된 초안은 유지됩니다. | "워크시트 다시 불러오기" 를 눌러 다시 시도한다 |
| {워크시트} 화면을 불러오는 중입니다. 값이 표시된 뒤 다시 만들어 주세요. | 화면이 다 뜨기를 기다린 뒤 다시 누른다 |
| 다른 화면에서 분석 또는 보고서가 변경되었습니다. | 워크시트를 다시 불러온 뒤 만든다. 교정 내용은 유지된다 |

### 3단계. 교정한다

만들어진 문서가 화면에 그대로 나온다. **칸을 눌러 그 자리에서 고칠 수 있다.**
제목, 문단, 표의 값과 머리글이 대상이다. 그림은 고칠 수 없다.

고친 곳 수가 "N곳 교정함" 으로 표시되고, "미리보기 기준으로 되돌리기" 로 한 번에
되돌릴 수 있다.

**교정은 보고서에만 저장된다.** 워크시트 원본은 바뀌지 않는다. 원본이 틀렸다면 그
워크시트에서 고치는 것이 맞다.

### 4단계. 초안을 저장한다

"초안 저장" 을 누른다. 저장 상태 카드가 지금 상황을 알려 준다.

| 표시 | 뜻 |
| --- | --- |
| 아직 저장하지 않은 변경사항이 있습니다. | 저장이 필요하다 |
| 마지막 저장 {일시} | 저장돼 있다 |
| 아직 저장된 초안이 없습니다. | 한 번도 저장하지 않았다 |
| 멘토가 완료하기 전에는 멘티에게 보고서가 공개되지 않습니다. | 아직 공개 전이다 |
| 수정 중에도 기존 완료본은 계속 공개됩니다. 다시 완료하면 새 문서로 교체됩니다. | 이미 완료본이 있다 |

용량 한도가 있다. 넘으면 이렇게 뜬다.

> 보고서 저장 용량(3.5MB)을 초과했습니다. 제품 사진의 크기나 보고서 내용을 줄인 뒤
> 미리보기를 다시 만들어 주세요.

대개 제품 이미지가 원인이다. 작은 이미지로 바꾸고 미리보기를 다시 만든다.

**저장하지 않고 화면을 떠나려 하면 확인 창이 뜬다.**

> 아직 저장하지 않은 입력과 교정 내용이 사라집니다. 저장된 초안과 기존 완료본은
> 유지됩니다. 계속 작성하려면 취소해 주세요.

### 5단계. 완료해서 공개한다

"완료" 를 누른다. **초안이 없거나 미리보기를 다시 만들어야 하는 상태면 버튼이 눌리지
않는다.** 확인 창 문구는 완료본이 있느냐에 따라 다르다.

- 처음이면 "현재 문서를 저장하고 완료본으로 공개합니다. 멘티가 열람하고 Word 파일을
  내려받을 수 있습니다."
- 이미 있으면 "현재 문서를 저장하고 기존 완료본을 교체합니다. 멘티에게 새 완료본이
  공개됩니다."

완료하면 "결과보고서를 완료했습니다. 멘티가 완료본을 열람할 수 있습니다." 가 뜬다.

**완료 뒤에도 초안을 계속 고칠 수 있다.** 고치는 동안에도 기존 완료본은 그대로
공개되고, 다시 완료를 누를 때 교체된다.

### 6단계. Word 로 내려받는다

"Word 내려받기" 를 누르면 화면에 보이는 문서가 그대로 `.docx` 로 만들어진다.
프로젝트를 볼 수 있는 사람이면 내려받을 수 있다.

## 8.5 자주 겪는 상황

| 상황 | 원인과 조치 |
| --- | --- |
| 멘토 분석이 보고서에 없다 | 저장 뒤 미리보기를 다시 만들지 않았다 |
| 그림이 비어 있다 | 워크시트 화면이 다 뜨기 전에 만들었다. 다시 만든다 |
| Kano 산점도 자리에 안내만 있다 | 설문 응답이 없다. 응답을 모은 뒤 다시 만든다 |
| 완료 버튼이 눌리지 않는다 | 초안이 없거나, 입력이 바뀌어 미리보기를 다시 만들어야 한다 |
| 저장이 용량 때문에 막힌다 | 제품 이미지를 작게 바꾸고 다시 만든다 |
| 멘티가 보고서를 못 본다 | 아직 완료하지 않았다 |
| 교정한 내용이 사라졌다 | 미리보기를 다시 만들면 교정이 교체된다 |
| 저장이 409 로 막힌다 | 다른 화면에서 같은 보고서를 고쳤다. 새로 고친 뒤 다시 한다 |
