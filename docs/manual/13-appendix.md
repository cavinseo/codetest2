## D. 용어집

### Kano 관련

| 용어 | 뜻 |
| --- | --- |
| Kano 모델 | 기능이 있을 때와 없을 때의 만족도를 함께 물어 품질 요소를 분류하는 방법 |
| 긍정 질문 (Functional) | 그 기능이 있을 때 어떻게 느끼는지 묻는 질문 |
| 부정 질문 (Dysfunctional) | 그 기능이 없을 때 어떻게 느끼는지 묻는 질문 |
| M · 당연적 (Must-be) | 있어도 티가 안 나지만 없으면 불만이다 |
| O · 일원적 (One-dimensional) | 잘할수록 만족이 올라간다 |
| A · 매력적 (Attractive) | 없어도 불만은 아니지만 있으면 크게 만족한다 |
| I · 무관심 (Indifferent) | 있으나 없으나 반응이 없다 |
| R · 역품질 (Reverse) | 오히려 없는 쪽을 원한다 |
| Q · 회의적 (Questionable) | 답이 앞뒤가 맞지 않는다. 질문을 의심한다 |
| 만족계수 (Better, SI) | (A+O) ÷ (A+O+M+I). 0 에서 1 |
| 불만족계수 (Worse, DI) | -((O+M) ÷ (A+O+M+I)). -1 에서 0 |
| TIMKO | 만족·불만족 계수로 항목을 사분면에 놓고 가중치를 매기는 방식 |
| 가중치 | TIMKO 위치에서 나오는 값. 0 에서 5. QFD 중요도로 넘어간다 |

| 수준향상률 | 기획품질 ÷ 자사 점수 |
| 절대중요도 | 가중치 × 수준향상률 |
| 요구품질 중요도 | 절대중요도의 백분율 |
| 품질중요도 | 기술특성 열마다 관계 강도와 가중치를 곱해 더한 값 |

## E. 알려진 화면과 동작의 차이

문서를 쓰면서 확인한, **화면 표시와 실제 동작이 다른 곳**이다. 사용자 안내에 그대로
쓰면 혼란이 생기므로 따로 모았다.

수정 계획은 `docs/superpowers/plans/2026-09-17-manual-ui-discrepancies.md` 에 있다.
항목을 고치면 **이 표의 해당 줄과 본문의 주의 문구를 함께 지운다.** 둘이 갈리면 이
문서가 다시 사실과 달라진다.

| 위치 | 화면에는 | 실제로는 |
| --- | --- | --- |
| 프로젝트 설정 → 팀원 초대 | 역할에 Editor 와 Coach 가 있다 | Coach 를 고르면 반드시 실패한다 |
| 프로젝트 설정 → 팀원 목록 | 휴지통 버튼이 있다 | 눌러도 아무 일도 없다. **팀원 한 명을 빼는 경로가 코드에 아예 없다** |
| 서비스 설정 → Google·SMTP | "서버 메모리에만 저장되며, 재시작 시 다시 입력해야 합니다." | 암호화되어 데이터베이스에 저장된다 |
| 서비스 설정 → AI 엔진 탭 | 서비스 AI 설정이 있을 것처럼 보인다 | 본인의 AI 연결 카드만 있다 |
| 새 프로젝트 → 사업계획서 | "PDF, DOC, DOCX, TXT (최대 10MB)" | XLSX 와 XLS 도 받는다 |
| 관리자 개요 → 시스템 정보 | 저장소·버전·환경·상태 | 고정 표시이며 실제 검사 결과가 아니다 |
| WS-7 주소 `kano/analysis` | 워크시트 메뉴에 링크가 있다 | 안내 화면이다. 실제 표는 개요 탭 |
| WS-4 | 메뉴와 탭이 같은 이름 | 주소로 연 화면과 개요 탭 화면이 서로 다르다 |
| WS-7 그래프 | 점이 눌리는 것처럼 보인다 | 눌러도 동작하지 않는다 |
| WS-15 | 다른 화면처럼 저장될 것 같다 | 성공은 알림 창, **실패는 아무 표시가 없다** |
| WS-16 AI 초안 | 버튼이 있다 | 항상 비활성이다 |
| WS-6 Google Forms 연동 | 3 단계 카드가 있다 | 개발 중이라 동작하지 않는다 |
| 기능분석 작성 도우미 | 이름이 WS-10 을 연상시킨다 | WS-2 화면에 있다 |
| 가져오기 이력 | 기록된다 | 조회 화면이 없다 |
| WS-6 기본 질문 문구 | 화면과 인쇄물이 한 문장을 쓴다 | 온라인 응답 화면만 다른 문장을 쓴다. 질문을 저장하면 통일된다 |
| Kano 분류 한글 이름 | 한 이름으로 보인다 | 화면마다 역품질·역, 회의적·의심·의문으로 다르게 나온다 |

이 목록은 고쳐야 할 후보이기도 하다. 코드가 바뀌면 이 표와 본문을 함께 갱신한다.

### 갱신할 때 지킬 것

- 화면 문구를 인용한 곳은 **코드의 문구를 그대로** 옮긴다. 요약하거나 다듬지 않는다.
- 문구가 바뀌면 본문과 부록 C 오류 사전을 함께 고친다.
- 부록 E 의 차이가 해소되면 그 줄을 지우고 본문의 주의 문구도 함께 지운다.
- 이 문서는 운영 데이터로 화면을 띄워 확인한 것이 아니라 화면 코드와 API 코드를
  근거로 쓴 것이다. 실제 화면과 다른 곳을 발견하면 코드를 먼저 확인한다.
