# 미완료 작업 마무리 및 단계별 인수 계획

사용자가 미완료 목록을 확인한 뒤 진행을 요청했다. 빌드 수정, DB 마이그레이션, 실제 PostgreSQL 검수, 병합·배포 순으로 진행한다.

- [x] 1. 빌드 복구. docx 9.7.1의 ImageRun 컴파일 오류를 확인하고 9.5.1로 고정했다. 프로덕션 빌드와 Word 문서 검사 5건을 통과했다.
- [x] 2. 격리 PostgreSQL에서 15개 마이그레이션 적용 및 통합 검수 10건 통과. 동시 생성 제한, 승인 일회 사용·롤백, 멘토 읽기 전용, 코멘트 접근 검증.
- [ ] 3. 운영 DB 대상과 기존 이력 및 적용 SQL 검토 완료. 적용 전후 테이블별 건수·해시 임시 보관에 대한 사용자 승인 대기. 승인 후 마이그레이션 적용과 기존 데이터 보존 확인.
- [x] 4. 실제 브라우저에서 프로그램 필터와 멘토·승인·코멘트 흐름 확인. 테스트 데이터는 격리 DB에서만 사용.
- [ ] 5. 전체 테스트·타입·린트 통과 후 커밋·푸시. main 대비 선행 변경 범위를 검토하고 병합.
- [ ] 6. 운영 배포 상태 및 읽기 요청 확인, 결과보고서 작성.

검수용 DB는 이 작업에서 생성한 localhost:65439 PostgreSQL이다. 운영 DB에 테스트용 회원·프로젝트를 만들지 않았다. 운영 비밀값이나 원본 금액을 새 파일로 내보내지 않았다. 자동 승인 검토가 운영 건수·해시의 임시 보관도 거절하여 명시적 승인을 요청했다. 승인 전에는 이에 의존하는 운영 DB 적용과 main 병합·배포를 진행하지 않는다.
