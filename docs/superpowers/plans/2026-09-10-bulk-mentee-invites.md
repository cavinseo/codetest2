# 멘티 초대 일괄 발급과 등록 이메일 발송.

## 계약 및 검수 기준.

- 초대 관리에서 줄바꿈·쉼표·세미콜론으로 여러 이메일을 입력한다. 공백과 대소문자를 정규화하고 중복을 제외한다. 잘못된 주소는 표시하며 유효 주소별로 기존 발급 API를 호출한다. 한 번에 최대 100명을 처리한다.
- 한 번의 사용자 동작으로 이메일별 코드를 발급하고 자동 발송한다. 기존 회원·유효 코드 중복 차단과 관리자·담당 프로그램 매니저 권한을 유지한다.
- 초대 목록의 저장된 이메일로 기존 코드를 개별 또는 선택 일괄 발송한다. 요청 본문에 임의 수신자나 코드를 지정할 수 없다. 멘티가 실제 로그인 가능한 코드만 발송하고 재발송으로 코드·사용일·이용기한을 변경하지 않는다.
- 코드 발급 성공과 메일 전송 성공을 구분한다. 일부 주소 또는 SMTP 오류가 있어도 나머지 항목을 처리하고 이메일별 결과를 표시한다. 메일 발송 실패 시 새 코드를 발급하지 않고 목록에서 다시 발송한다.
- 실제 수신자에게 시험 메일을 발송하지 않는다. 격리 로컬 DB와 로컬 SMTP 수신기를 이용해 확인한다.
