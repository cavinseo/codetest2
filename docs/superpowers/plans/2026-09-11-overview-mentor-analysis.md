# 개요 보강과 워크시트 멘토 분석 연동

## 마지막 개발 요청 원문과 재개 위치

> 개요에 추가되어야 하는 사항
>
> 1. 제품(서비스) 명
> 2. 제품 이미지
> 3. 시장정의
> 4. 목표 고객
>
> 다음 워크시트에는 '멘토만 작성하고  볼 수 있는 분석(보고) 기능추가하고 이 곳에 작성한 내용은 결과보고서의 해당 워크시트 부분에 반영한다.)
>
> 적용 워크시트는 ws-2,ws-3, ws-4, ws-12(최종목표스펙 항목별 설명), WS-15(핵심자산, 보완자산), ws-13(개선제품(서비스)명 및 개선제품 설명 ,ws-16,ws-17

2026-09-11 추가 지시를 반영하여 2·3단계 구현과 4단계 핵심 기능 검수를 완료했다. 후속 푸시·배포 지시에 따라 운영 DB 마이그레이션과 Vercel 운영 배포도 완료했다. 구현 증거와 검수 한계는 같은 보고서 폴더의 task-2.md에, 운영 반영 결과는 task-deployment.md에 기록한다.

후속 지시와 적용 기준은 다음과 같다.

1. “남은 작업을 진행하고 멘토에게 멘티의 프로젝트를 수정할 수 있도록 권한을 주어라”, “배정받은 멘티의 프로젝트만 수정가능”이라는 지시를 받았다.
2. 현재 소유 멘티에게 배정된 멘토만 프로젝트 내용을 편집한다. 과거 멤버 역할로 배정 제한을 우회할 수 없다. 실제 멘토로 배정된 프로그램 매니저도 같은 편집 권한을 받는다.
3. 최초 구현에서는 분석 초안을 배정 멘토만 조회·작성하도록 했다. 2026-09-11 후속 지시 “관리자는 볼수 있도록 하라”에 따라 관리자의 읽기 전용 초안 열람을 추가했다. 작성·저장·완료는 배정 멘토만 허용하며 미배정 프로그램 매니저는 초안에서 제외한다. 보고서 완료 후에는 멘티가 분석이 포함된 완료본을 볼 수 있다. 수정 중에는 이전 완료본을 유지한다.

## 요구사항과 보존 기준

- 개요에 프로젝트명과 별도의 제품(서비스)명, 제품 이미지, 시장정의, 목표 고객을 저장한다.
- 기존 프로젝트 데이터와 완료 보고서를 일괄 수정하지 않는다. 신규 필드는 선택 항목으로 추가한다.
- WS-2, WS-3, WS-4, WS-12, WS-13, WS-15, WS-16, WS-17에 멘토 분석(보고) 작성 영역을 둔다. 기존 공개 ‘멘토 의견’과 분리한다.
- WS-12는 최종 목표 스펙 항목별 설명, WS-13은 개선 제품명과 설명, WS-15는 핵심자산과 보완자산 분석을 구분한다.
- 저장된 분석은 결과보고서 미리보기의 해당 워크시트 부분에 반영한다. 기존 완료본은 다시 완료하기 전까지 유지한다.
- 분석 초안은 배정 멘토와 관리자만 열람하며, 관리자는 읽기 전용이다. 결과보고서 완료 시 멘티에게 공개한다. 프로젝트 삭제·소유권 이전·회원 관리 권한은 멘토 편집 권한에 포함하지 않는다.

## 단계별 실행과 검수

### 1. 개요 저장과 화면

- [x] 신규 필드 마이그레이션과 서버 입력 검증을 추가한다.
- [x] 개요의 편집·조회·취소에 네 항목을 연결한다. 이미지 최적화와 크기 제한을 적용한다.
- [x] 누락 필드의 기존 값 보존과 이미지 검증을 테스트한다. 멘토의 원본 수정 거절은 당시 정책이며 후속 지시로 현재 배정 멘토에게만 허용하도록 변경했다.

### 2. 멘토 분석 저장과 권한

- [x] 지정한 8개 워크시트만 지원하는 분석 입력 계약을 정의한다.
- [x] 기존 결과보고서 초안 저장 구조를 재사용하고 버전 충돌을 검사한다.
- [x] 조회·저장 권한을 서버에서 강제한다. 멘티·미배정 멘토에게 초안을 제공하지 않으며 쓰기를 거절한다.
- [x] 다른 워크시트 분석과 기존 보고서 교정 내용을 덮어쓰지 않는지 검증한다.

### 3. 결과보고서 연결

- [x] 개요의 신규 필드와 워크시트 분석을 해당 보고서 절에 넣는다.
- [x] 기존 보고서 전용 입력은 보존하며 신규 원본이 없는 경우 호환한다.
- [x] 분석 수정 시 미리보기 갱신 필요 상태와 버전을 갱신한다. 완료본은 보존한다.
- [x] 미리보기와 Word 문서의 항목 매핑 및 완료본 공개 경계를 테스트한다.

### 4. 통합 검수

- [x] 관련 테스트, 전체 테스트, lint, build를 실행한다.
- [x] 격리 로컬 DB에서 마이그레이션·권한·저장·보고서 생성을 확인한다.
- [x] 브라우저에서 편집·저장·재조회와 멘토 전용 표시를 확인한다.
- [x] 검수 결과와 배포 전 필요한 DB 반영 절차를 기록한다. 후속 요청에 따라 운영 DB 반영·푸시·운영 배포와 정식 주소 검수를 완료했다.
