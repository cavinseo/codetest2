# 관리자 프로그램 삭제.

관리자가 프로그램 관리 화면에서 지정한 프로그램을 삭제한다. 사용자는 프로젝트와 멘티를 다른 프로그램으로 먼저 옮긴 후 삭제하는 방식을 선택했다.

## 계약 및 검수 기준.

- 관리자에게만 삭제 버튼을 표시하며 GET 미리보기와 DELETE 모두 서버에서 관리자 권한을 검사한다.
- 프로젝트 또는 소속 회원이 남으면 삭제하지 않고 이동이 필요한 건수를 안내한다. 다른 프로그램으로 이동한 회원의 사용된 초대코드도 보존하여 로그인과 이용 기한 판정을 바꾸지 않는다.
- 삭제 가능한 프로그램은 확인창에 프로그램명, 초대코드 및 개설 신청 이력 건수를 표시한다. 확인한 경우 해당 프로그램과 연결된 미사용 초대코드·개설 신청 이력만 삭제한다.
- 삭제 직전에 트랜잭션과 프로그램 행 잠금으로 연결 상태를 재검사한다. 경합하면 새로 확인하도록 안내하고, 프로젝트·회원은 자동 이동하거나 삭제하지 않는다.
- 브라우저 기본 확인창 대신 앱 내부 확인창을 사용한다. 취소, 처리 중 중복 클릭 방지, 오류 유지, 성공 후 목록 갱신을 검증한다.
- 스키마 변경과 운영 데이터 삭제는 수행하지 않는다.

- [x] 구현. `app/api/programs/[id]/route.ts`에 삭제 미리보기·실행 API를 추가한다. `components/admin/ProgramsTab.tsx`와 `app/admin/page.tsx`에 관리자 전용 삭제 및 확인창을 연결한다.
