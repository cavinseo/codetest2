# Timko 만족·불만족 계수 막대그래프 추가

## 요청과 성공 기준.

첨부 예시의 좌우 막대그래프와 고객만족계수 설명을 WS-7에 추가한다. 기존 산점도와 집계표를 유지하며 같은 분석 결과를 표시하는 WS-6 분석 보기에도 공통 컴포넌트를 연결한다.

- 고객요구사항의 전달 순서를 유지한다.
- 불만족(Worse)은 음수·왼쪽·노랑, 만족(Better)은 양수·오른쪽·주황으로 표시한다.
- 요구사항 전체 문구와 계수 값을 읽을 수 있게 표시한다.
- 만족 (A+O)/(A+O+M+I), 불만족 −(O+M)/(A+O+M+I), 범위와 A/O/M/I 해석을 함께 제공한다.
- 유효응답(A+O+M+I)이 0인 행은 계산 대상 응답이 없음을 표시한다.
- 기존 담당 멘토/배정 매니저 및 관리자 열람 권한을 유지한다.
- WS-7 전체 그림 다운로드에 포함된다. 결과보고서 전용 .timko-chart 산점도 캡처는 기존 상태를 유지한다.

## 검토.

계수는 API에서 이미 계산되고 불만족 계수는 음수이다. 새 계산이나 저장을 하지 않고 전달된 값을 표시한다. 독립 WS-7은 변환 과정에서 집계값을 버리므로 이름을 붙인 원래 분석 행을 사용한다. 보고서 캡처의 기존 SVG 클래스와 부모를 변경하지 않는다. API·DB·스키마 변경은 없다.
