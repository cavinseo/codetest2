### 3.1 "판(version)"의 범위

판은 **설계한 모델과 그 모델의 평가**를 한 묶음으로 얼린 것이다. BM-05·06·07·08·09·10·12·15·16 이 판에
속한다. 강의의 Step 1→2→3 은 캔버스만이 아니라 가치제안과 수익 구조가 함께 바뀌었고, 점검 점수와
손익도 판끼리 비교해야 고도화 효과가 드러나기 때문이다.

판에 속하지 않는 것: 아이템 정리(BM-01~04)는 사실·조사라 판마다 복제하지 않는다. 가설(BM-11)은 판을
가로질러 쌓이며, 각 가설이 **어느 판에서 나왔는지**와 **어느 판을 만든 근거인지**를 기록한다.

판 상태는 `초안 → 검증 중 → 확정`이다. 확정된 판은 읽기 전용이고, 고치려면 새 판을 만든다.

## 4. 공통 화면 구조

```
┌ 상단 바 ─────────────────────────────────────────────────────────────────────┐
│ 프로그램 › 과제명   [판 v3 · 검증 중 ▾]   저장됨 14:02   [작성|검토|발표]  [멘토 검토 요청] │
├──────────────┬─────────────────────────────────────────────┬─────────────────┤
│ 단계 레일      │ 작업 영역                                      │ 맥락 패널(접힘 가능) │
│ 1 아이템 정리 ◔ │  워크시트 제목 · 이 페이지가 답하는 질문 한 줄      │ [가이드|사례|의견|분석] │
│   BM-01 ●     │  오버레이: [그룹][위험][근거][변화]                  │ 선택한 블록의 강의 질문 │
│   BM-03 ◐     │                                               │ 체크 · 관련 사례 ·    │
│ 2 가치 설계 ◑  │  (캔버스 / 표 / 매트릭스)                          │ 카드에 핀 꽂힌 멘토 의견 │
│ ...           │                                               │                 │
│ 다음에 할 일    │  하단: 이 워크시트의 멘토 분석(배정 멘토 작성)         │                 │
└──────────────┴─────────────────────────────────────────────┴─────────────────┘
```

- **단계 레일.** 단계별 진행 고리와 워크시트별 상태 점(빈칸·작성 중·완료). 맨 아래 "다음에 할 일" 카드
  하나가 완성도 엔진의 첫 미완 항목을 알려준다. 잠그지 않는다(P1).
- **판 선택기.** 현재 판과 상태를 항상 보여준다. 지난 판을 고르면 화면 전체가 읽기 전용 회색 띠로 바뀐다.
- **모드.** 작성(입력), 검토(오버레이·의견 중심, 입력 잠금), 발표(블록 확대·한 블록씩 넘기기, 상단 바 숨김).
- **맥락 패널.** 가이드는 강의의 구성요소별 질문을 체크리스트로 보여준다. 사례는 강의 사례(네스프레소,
  힐티, 롤스로이스, 에어비앤비, 다이슨 등)의 캔버스 요약. 의견은 카드·블록에 고정된 멘토 의견. 분석은
  워크시트 멘토 분석(QFD 와 같은 권한 규칙).
- **반응형.** 1280px 이상 3단. 1024px 이하 맥락 패널이 서랍으로 접힌다. 768px 이하 단계 레일이 상단
  가로 칩으로 바뀌고, 캔버스는 블록 단위 세로 쌓기로 바뀐다(편집은 가능, 발표 모드는 데스크톱 권장).

## 5. 핵심 워크시트 화면

### 5.1 BM-07 비즈니스 모델 캔버스 (중심 화면)

- 실제 캔버스 배치(KP | KA·KR | VP | CR·Ch | CS / C$ | RS). 각 블록은 카드 목록이다.
- **카드**는 한 줄 주장이다. 카드에 붙는 것: 세그먼트 색 점(P8), 근거 배지 E0~E4(P5), 가설 표시(P6),
  의견 수, 연결 손잡이.
- 입력: 블록 빈 곳 더블클릭 또는 `N` 으로 카드 추가, `Enter` 저장, 드래그로 순서·블록 이동,
  `Alt+↑↓` 로 키보드 이동. 세그먼트 색은 카드 메뉴에서 고른다.
- **오버레이 4종**(동시에 하나 이상 켤 수 있다)
  - 그룹: 블록 머리를 Front·Back·Number 색으로 칠한다(P3).
  - 위험: BM-09 점검 결과로 블록마다 신호등(높음·보통·낮음, 아이콘+글자 병기).
  - 근거: 근거가 약한 카드는 점선 테두리, 강한 카드는 실선.
  - 변화: 직전 판 대비 추가(＋)·수정(～)·삭제(－, 흐린 유령 카드) 표시.
- **연결.** VP 카드에서 CS 카드로, RS 카드에서 BM-12 매출 행으로 연결한다. 연결된 카드를 고르면 상대가
  강조된다. 연결이 끊긴 VP(어느 세그먼트에도 닿지 않는 가치)는 경고 표시.

### 5.2 BM-05 가치제안 캔버스 + BM-06 가치제안서

- 왼쪽 가치 도면(제품·서비스 / 불만 해소 / 혜택 창출), 오른쪽 고객 프로필(고객활동 / 불만 / 혜택).
  세그먼트 탭으로 고객 프로필을 바꾼다.
- **적합(fit) 선.** 불만 해소 카드를 불만 카드에, 혜택 창출 카드를 혜택 카드에 잇는다. 이어지지 않은
  불만은 "해결하지 않은 불만"으로 모인다. 적합률(이어진 중요 불만·혜택 비율)을 상단에 표시.
- 강의의 흔한 실수 3가지(세그먼트 혼합, 활동과 결과 혼동, 기능적 활동만 기술)를 저장 시 가벼운 점검
  문구로 알려준다. 막지 않는다.
- BM-06 은 문장 틀 ①~⑦ 의 빈칸을 BM-05 에서 고른 카드로 채운 초안을 보여주고 사용자가 고친다.
  초안과 다른 부분은 사용자가 쓴 것으로 남는다.

### 5.3 BM-09 가능성 점검 + BM-10 성과 검토

- 점검은 블록별 체크 문항(예/아니오/모름)이다. 모름은 아니오로 세지 않는다(QFD 보고서 계획의 미응답
  원칙과 같다). 결과는 수용·실현·생존·적응 4축 점수.
- 4축 레이더에 **현재 판과 직전 판을 겹쳐** 그린다. 고도화의 효과가 숫자로 보인다.
- 성과 검토는 질문마다 −3~+3 척도. Front·Back·Number 평균을 막대로, 가장 낮은 질문 3개를 "다음 판에서
  다룰 약점"으로 뽑아 BM-13 으로 넘긴다.

### 5.4 BM-11 가설·실험 보드

- 가설 카드 문장 틀: "우리는 ( )라고 믿는다" + 반증가설 + 유형(수용·실현·생존·적응) + 출처 블록.
- **중요도 × 증거 매트릭스.** 세로 중요도, 가로 증거 강도. 왼쪽 위(중요하지만 증거가 약함) 사분면이
  "먼저 검증"으로 강조된다. 카드를 끌어 놓아 배치한다.
- 카드를 뒤집으면 실험 카드(실험 방법·지표·성공 기준·기간·비용), 다시 뒤집으면 학습 카드(관찰·학습·
  결정: 유지·수정·피봇). 상태 `계획 → 진행 → 입증/기각`. 입증·기각에는 결과가 필수다.
- 기각된 가설은 BM-13 피봇 설계의 근거 후보로 바로 나타난다.

### 5.5 BM-12 Number 워크벤치

엑셀 정본의 9개 시트를 3개 하위 탭으로 묶는다.

| 하위 탭 | 엑셀 시트 | 화면 |
| --- | --- | --- |
| 매출 | 자사추정매출액(제품·상품·서비스), 요약표, 판매방식 | 아이템 × 예상거래업체 × 기간(연/월 토글), 수량·가격 입력 → 합계 계산 |
| 원가·판관비 | 생산방식, 제품매출원가(BOM), 상품매출원가, 서비스매출원가, 판매전략(인건비·판관비) | 원가 유형별 표, 인원별 급여 표 |
| 손익 | 추정손익계산서 | Yt+1~3 손익계산서(읽기 전용 계산) + 결과 차트 |

- **입력 칸과 계산 칸을 색으로 구분**하고 계산 칸에는 수식을 말로 보여준다("수량 × 가격").
  엑셀 정본에서 보인 `#DIV/0!`·`#REF!` 류 오류가 생기지 않게 0 나눗셈은 빈칸(—)으로 그린다.
- **가정값 패널**: 퇴직급여(연봉의 1/12), 복리후생비율(5~12% 슬라이더), 법인세(최저한세 10%). 엑셀
  비고란의 규칙을 그대로 기본값으로 쓴다.
- 결과 차트: 연도별 매출 막대 + 영업이익 선, 손익분기 연도 표시. 판 비교 시 직전 판 선을 흐리게 겹친다.
- 캔버스의 수익원 카드 ↔ 매출 아이템, 비용 카드 ↔ 원가 항목을 연결한다(P2).

### 5.6 BM-13 피봇 설계 → 새 판, BM-14 판 비교

- "고도화 시작" 마법사 3단계: ① 근거 고르기(기각된 가설, 성과 검토 약점, 위험 블록) ② 피봇 패턴 고르기
  (가치제안 전환·How to Sell·How to Make·이익공식, 강의의 하위 패턴 목록) ③ 변경 사유 작성 →
  직전 판을 복사한 새 판이 열리고, 변화 오버레이가 켜진 채 시작한다.
- BM-14 타임라인: 판마다 상태·날짜·사유·근거 가설·4축 점수 변화. 두 판을 골라 캔버스를 나란히 놓고
  블록별 추가·삭제·유지를 보여준다.

## 9. 데이터 모델 영향 (계획서 §6.2 수정 사항)

계획서 §6.2 의 모델 9개를 아래처럼 바꾼다. 구현 계획서 갱신 때 Prisma 스키마로 확정한다.

- **추가**: `BmVersion`(판: 번호·상태·사유·근거 가설·만든 사람) — 판에 속하는 모든 행이 `versionId` 를 가진다.
  `BmItemSummary`(BM-01, 1:1), `BmFeature`(BM-02), `BmPersonaProblem`(BM-03, 출처 포함),
  `BmCompetitor`(BM-04), `BmValueStatement`(BM-06), `BmPatternChoice`(BM-08), `BmCheckAnswer`(BM-09),
  `BmScore`(BM-10), `BmRevenueLine`·`BmCostLine`·`BmPnlAssumption`(BM-12), `BmPivot`(BM-13),
  `BmStory`(BM-15), `BmCardLink`(카드 간 연결).
- **변경**: `BmCanvasVersion` → `BmVersion` 으로 일반화. `BmCanvasItem`·`BmValueItem` 에 `segmentId`·
  `evidenceLevel`(0~4) 추가. `BmHypothesis` 에 `type`·`importance`·`evidence`·실험·학습 필드와
  `originVersionId` 추가.
- **삭제**: `BmProfile`(BM-01 로 흡수), `BmRevenueStream`·`BmUnitEconomics`·`BmCostItem`(엑셀 정본 구조인
  매출·원가 행으로 대체). 단위경제(LTV·CAC)는 v2 에서 매출 탭의 선택 지표로 둔다.
- 판 복사는 트랜잭션 안에서 과제 행을 잠그고 판에 속하는 표를 통째로 복사한다(계획서 Task 7 의 잠금 규칙).
- 2026-10-08 승인 후 계획서 §6.3 이 v1 스키마(테이블 11개)의 정본이다. 이 절은 영향 요약으로 남긴다.
