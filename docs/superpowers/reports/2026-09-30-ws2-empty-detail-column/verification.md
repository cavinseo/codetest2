# WS-2 빈 세세부기술 열 접기 및 보고서 제외.

## 적용 내용.

- WS-2 수동 조작 화면에 세세부기술 접기·펼치기 버튼을 추가했다. 전체 행의 세세부기술이 비어 있거나 공백만 있을 때 접을 수 있다.
- 한 행이라도 내용이 있으면 열을 표시하고 접기 버튼을 비활성화한다. `+D`로 항목을 추가하거나 내용이 있는 데이터를 불러오면 열을 펼친다.
- 접기는 화면 상태만 변경한다. 기존 행, 적용기술, 스펙 저장 구조는 유지하며 접기 자체로 저장 요청을 보내지 않는다.
- 보고서 생성 시 WS-2 세세부기술이 모두 비어 있으면 머리글·각 행의 해당 셀·해당 열 폭만 제외한다. 나머지 열이 표 너비를 나누어 사용한다. 내용이 있으면 기존 5열을 유지한다.
- 동일 문서 모델을 사용하는 미리보기와 Word에 함께 적용된다. 기존 저장 보고서는 미리보기를 다시 만들어 반영한다. DB 구조나 저장 문서는 자동 변경하지 않는다.

## 테스트.

- 구현 전 회귀 테스트에서 기존 화면의 접기 기능 부재와 보고서의 빈 열 노출을 확인했다.
- UI 테스트 6개를 추가했다. 접기·펼치기, 접은 상태의 저장 값 보존, 추가 시 펼치기, 내용 유무·공백 구분, 빈 표의 colspan, 데이터 갱신 후 입력 칸 유지를 검증한다.
- 보고서 테스트 3개를 추가했다. 빈 문자열·공백의 열 제외, 모든 행 및 적용기술 보존, 내용이 있는 경우의 전체 열 표시, 원본 불변을 검증한다.
- 전체 190개 테스트 파일, 2,848개 테스트가 통과했다. 실행 명령은 `npm run test -- --maxWorkers=2`이다.
- 전체 린트, `tsc --noEmit --incremental false`, 프로덕션 빌드, Git diff 공백 검사가 통과했다.

## 브라우저 및 Word 확인.

- 프로덕션 빌드를 로컬 Chrome에서 실행하고 AI PLC 관리 장비의 저장 조회본을 테스트 입력으로 사용했다.
- WS-2를 접으면 세세부기술 열만 사라지고 적용기술 41개가 유지됐다. 접은 상태에서 저장한 세부기술의 적용기술 값도 원래 화면과 같았다.
- 펼치기와 `+D`로 새 입력 행을 추가하는 동작을 확인했다. 내용을 입력하면 접기 버튼이 비활성화됐다.
- 결과보고서 미리보기는 No·핵심기술·세부기술·적용기술의 4열이었다. 다운로드한 Word XML의 WS-2 표도 같은 4열이며 41개 행의 모든 셀 값이 생성 모델과 같았다.
- 전체 보고서 21쪽, 고객요구사항 15개, 단계별 문단 서식, 교정·저장·재열기·완료본 열람·이미지 및 Word 다운로드를 확인했다. 화면 넘침과 브라우저 오류는 0건이었다.
- API는 테스트 응답으로 대체했고 운영 데이터 쓰기는 0회다. Word는 파일 생성·다운로드와 XML 구조를 확인했으며 Word 앱의 실제 인쇄 렌더링은 확인하지 않았다.
- 기존 작업 폴더의 대상 파일이 작업 전 기준과 같은지 검사한 뒤 이번 4개 소스·테스트 파일만 동기화했다. 로컬 검증 서버는 종료했다. 이번 요청에서 푸시·배포는 수행하지 않았다.
