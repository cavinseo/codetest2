# 상세 제품개요 자동 글머리.

## 변경 내용.

- 상세 제품개요 편집기에 점·동그라미·사각형·대시 글머리와 글머리 제거 버튼을 추가했다.
- 현재 줄 또는 선택한 여러 줄에 적용한다. 기존 글머리를 바꿀 때 중복 기호를 붙이지 않고 본문과 들여쓰기를 보존한다.
- 글머리 항목에서 Enter를 누르면 같은 기호를 이어 쓴다. 빈 항목의 Enter는 글머리를 지워 목록을 종료한다. Shift+Enter는 기본 줄바꿈이다.
- 사용자가 직접 입력한 `-`, `*`, `•`, `·`, `○`, `▪` 글머리도 이어 쓴다. 한글 조합 중 Enter와 IME 키 코드 229는 가로채지 않는다.
- 기존 상세 설명 문자열에 기호와 줄바꿈을 저장한다. API·DB 구조와 결과보고서의 본문 전달 방식은 변경하지 않았다.

## 검증 결과.

- 관련 순수 함수·실제 React DOM 테스트 26개가 통과했다. 커서 중간 분할, 선택 본문 교체, 여러 줄 선택, 기존 본문 보존, 빈 항목 종료, 한글 조합, 저장·재열기·취소를 포함한다.
- 전체 린트, 188개 파일·2,832개 테스트, 프로덕션 빌드, Git diff 공백 검사가 통과했다.
- 로컬 프로덕션 화면을 Chrome에서 실행했다. 실제 키보드 입력으로 점 글머리 추가, Enter 자동 이어쓰기, 빈 항목 종료, 여러 줄의 기호 변경·제거, 직접 입력한 대시 이어쓰기, Shift+Enter, 저장·새로고침과 취소 후 원문 보존이 통과했다.
- 브라우저 검증은 API 임시 응답을 사용했다. 임시 저장 1회, 운영 저장 0회이며 브라우저 오류는 없었다. 로컬 웹 서버는 종료했다.
- 결과와 화면은 `temp_files/overview-bullets-browser/result.json` 및 `bullet-editor.png`에 있다. 전체 검사 로그는 `temp_files/overview-bullets-{lint,tests,build}.log`에 있다.
