# WS-5 고객요구사항 그룹 계층과 보고서 병합

## RESULT

사용자가 확정한 2차 그룹 → 1차 그룹 → 요구사항 계층을 적용했다. 그룹과 항목은 기존 순서에서 처음 등장한 순서를 유지한다. 화면의 열 순서는 No·항목·1차 그룹·2차 그룹을 유지한다.

WS-5를 처음 조회할 때부터 같은 그룹의 행을 모으고, 그룹 셀은 세로로 병합하여 가운데에 한 번 표시한다. 2차 그룹 셀은 그 안의 여러 1차 그룹을 포함한다. 1차 그룹은 서로 다른 2차 그룹 사이에서 합치지 않는다. 편집 중에는 해당 행 앞뒤의 병합을 나누어 두 그룹 입력칸을 제공하고 편집을 마치면 다시 묶는다.

새 결과보고서와 표 갱신에도 동일한 정렬과 병합을 적용했다. 미리보기와 Word에서 병합과 모든 요구사항 내용의 보존을 검증했다. PDF는 같은 미리보기 DOM을 사용하는 기존 경로를 유지했다. 빈 2차 그룹도 WS-5 화면과 보고서에서 동일한 병합 범위로 처리한다.

항목을 삭제하거나 같은 내용의 요구사항을 자동으로 합치지 않는다. 기존 AI 추가의 중복 방지 동작은 유지했다. 저장 시 항목 ID·분류값·본문을 보존하여 Kano 응답과 QFD 연결을 유지한다. DB·스키마·API에는 변경을 하지 않았다.
