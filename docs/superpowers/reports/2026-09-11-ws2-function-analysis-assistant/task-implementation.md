# WS-2 기능분석 프롬프트 작성 도우미 구현 결과.

## RESULT.

- 사용자 정정에 따라 도우미를 외부 AI용 프롬프트 생성 기능으로 구현했다. WS-2의 ‘기능분석 작성 도우미’를 누르면 제품·사용자, 현행 대안·고객가치, 기능·제약·범위를 순서대로 묻는 팝업이 열린다.
- 프로젝트명과 설명을 미리 채우며, 필수 답변 5개를 확인한다. 선택 답변이 비어 있으면 ‘미제공·확인 필요’로 명시한다. 이전/다음과 팝업 닫기/재열기에서 답변을 유지하며, 페이지를 벗어나면 초기화됨을 안내한다.
- 현재 WS-2 참고 자료의 포함 여부를 선택하고 프롬프트 전체를 검토·복사한다. 자동 복사와 전체 선택을 제공한다.
- 지정된 FAST 스킬의 분석 규칙과 고정된 8개 출력 절, WS-2의 4열 표 형식을 본문에 포함했다. 외부 AI가 GitHub 링크를 열지 못해도 분석 규칙을 읽을 수 있다. 동일 입력은 동일 프롬프트를 만든다.
- 현재 기능과 새로운 제안을 분리하고, 미확인 기술·수치·VOC를 사실로 만들지 않도록 지시한다. 모델 간 분석 내용 자체가 같다고 보장하지 않는다는 안내를 표시한다.
- 도우미는 기존 작성 역할 OWNER·EDITOR·ADMIN에 제공한다. 기존 워크시트 편집·저장 API, AI 에이전트 및 보고서 기능은 변경하지 않았다.
