# 샘플 양식의 결과보고서 적용 및 검증.

## 적용 범위.

- 승인된 AI PLC 관리 장비 샘플의 표지와 Ⅰ~Ⅴ장 순서를 새 보고서 생성에 적용했다.
- 표지는 기업명과 배정 멘토명을 자동으로 연결하고, 작성일은 한국 시간의 출력일로 표시한다.
- 제품 정의는 개요에서 읽으며, WS-2부터 멘토 분석을 해당 결과보다 먼저 배치한다.
- WS-15·16·17을 포함하고 미입력 값, 미작성 결과 및 저장된 0을 구분한다.
- 미리보기와 Word가 같은 A4 줄바꿈·페이지 분할 계산을 사용한다. 긴 표는 머리글을 반복하고 모든 행을 보존한다.
- 기존 저장 문서는 기존 형식으로 열리며, 사용자가 미리보기를 다시 만들면 새 양식으로 바뀐다. 교정·저장·완료·그림 다운로드 기능을 유지한다.

## 검증 결과.

- `npm run lint` 통과.
- `npm run test` 186개 파일, 2,796개 테스트 통과.
- `npm run build` 통과.
- 실제 프로젝트의 저장 조회본을 로컬 API 응답으로 공급하고 Chrome에서 생성·교정·저장·재열기·완료본 열람·그림 및 Word 다운로드를 검증했다.
- 미리보기 20쪽, WS-2 세부기술 41행, 고객요구사항 15개를 확인했다. 페이지 여백 초과, 가로 잘림, 브라우저 오류는 없었다.
- 긴 본문·한 페이지보다 긴 표 셀의 분할, 표 머리글 반복, 한국 날짜 경계, 저장 모델 보존, Word 문서의 구역·행·이미지 구조를 자동 검증했다.
- 운영 DB의 보고서나 워크시트에 쓴 데이터는 없으며 배포는 수행하지 않았다.

## 확인 범위의 한계.

- 이 환경에 Word 또는 LibreOffice가 없어 Word 앱의 실제 인쇄 렌더링은 확인하지 못했다. Word 검증은 파일 생성·다운로드와 XML 구조 검사까지 수행했다.
- 사례 프로젝트의 개요 상세 필드와 멘토 분석은 미작성 상태를 유지했다. 원본 양식의 제품 진단표에 대응하는 입력란도 없어 임의의 진단 결과를 채우지 않았다.
