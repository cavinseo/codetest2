  함께 지운다 — 코드에서 따로 지우지 않는다.

  생겨 실제 열이 15개가 되면 머리글 `select` 로 세부기능을 고르는 길이 닫혔다.

  그대로 두었다.

## RISKS

- **게이트 미실행**: 이 세션은 `node_modules` 가 없고 `npm install` 이
  `registry.npmjs.org` 에 직결·프록시 양쪽 다 403 으로 막혀 있다(2026-09-07
  보고서에 근거 기록). `npx tsc --noEmit` / `npx vitest run` / `npx next lint` 를
  돌리지 못했다. **새 테스트 파일이 포함된 변경이라 CI 결과 확인이 특히 중요하다** —
  mock 형태가 라우트와 어긋나면 테스트 자체가 먼저 깨진다.
- **실화면 미검증**: 삭제 후 중요도·RANK 재계산이 화면에서 정상인지, "+ 세부기능"
  이 15칸을 넘겨 동작하는지 브라우저로 확인하지 못했다(dev 서버 기동 불가 + CLAUDE.md
  정책). 사용자·감리자 몫으로 이월한다.
- **접힘 그룹 인덱스 어긋남**: 그룹 접힘 상태는 열 순번 기준이라, 열을 추가·삭제하면
  접어 둔 그룹의 경계가 밀린다. 이번 작업이 만든 성질이 아니라 원래 그러했고
  (열 추가 시에도 같다), '전체 펼치기'로 복구된다. 범위 밖으로 두었다.
- **빈 칸 카운트의 미세한 동작**: 실제 열이 15개 미만일 때 "+ 세부기능"으로 늘린
  칸을 채우면, 기본 빈 칸이 자동으로 하나 줄고 늘린 칸도 하나 줄어 전체 열 수가
  15로 돌아간다. 이미 빈 칸이 많은 상황이라 기능상 잃는 것은 없지만, 의도한 동작임을
  기록해 둔다(15개 이상일 때는 늘린 칸이 실제 열로 그대로 남는다 — 이 경우가 원래
  막혀 있던 경로다).
