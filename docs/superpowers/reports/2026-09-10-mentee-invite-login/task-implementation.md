# 멘티 초대 코드 로그인 적용 결과

## RESULT

확정된 정책의 구현과 로컬 검수를 완료했다. 멘티는 발급 대상 이메일과 개인 코드로 로그인하며, 최초 로그인 시 계정에 연결된다. 이용 기한은 최초 로그인 후 90일과 프로그램 종료 중 빠른 시점이다. 재로그인으로 연장하지 않는다. 프로그램 종료 시 미사용·사용 중 코드 모두 만료로 표시하고 기존 세션의 보호 API 접근도 차단한다.

최초 로그인에는 비밀번호를 요구하지 않는다. 프로필이 미완성이면 로그인 후 기존 프로필 작성 화면으로 이동한다. 관리자와 담당 프로그램 매니저만 멘티 코드를 발급하며, 같은 이메일의 유효 코드를 중복 발급하지 않는다.

- 초대 발급 API, 메일 템플릿, `InvitesTab`. 멘티 전용·90일 정책, 개인 코드 중복 발급 제한, 실제 만료일과 이용 상태를 반영했다.
- 가입 API·화면. 코드 가입 완료 시 세션을 발급하여 최초 로그인 시점과 기간 시작을 일치시킨다. 일반 가입의 승인 대기는 유지한다.
- 관련 단위 테스트와 `tests/integration/invite-login.integration.test.ts`. 인증 경계와 실제 PostgreSQL 동시 요청을 검수한다.

DB 스키마나 마이그레이션은 이번 기능에서 추가하지 않았다.

## REVIEW AND DEVIATIONS

독립 검토에서 이메일 대소문자 조회 불일치와 미사용 과거 코드의 기간이 진입 경로마다 다른 문제를 발견하여 회귀 테스트와 함께 수정했다. 기존 혼합 표기 이메일의 중복 가입도 거절한다. 사용 중 코드 삭제 가능성을 전제로 한 지적은 기존 삭제 API가 사용 코드를 거절하므로 해당하지 않는다.

기존 발급 대상 이메일 제한을 유지하면서 최초 사용자 계정에 연결한다. 기존 사용 코드의 옛 가입 유효기간은 반복 로그인에 적용하지 않고, 최초 사용 후 90일·기존 회원 만료일·프로그램 종료 중 빠른 시점을 적용한다. 기존 이용 중 회원의 더 짧은 만료일을 연장하지 않는다. 과거 미사용 코드의 최초 사용 가능 기한은 유지한다.

## RISKS AND QUESTIONS

실제 외부 이메일 발송이나 Google 제공자 로그인은 이번 검수에서 실행하지 않았다. 메일 템플릿과 API 테스트를 검증했고, 실제 DB·브라우저 검수는 격리된 로컬 테스트 계정만 사용했다.

사용자의 후속 요청에 따라 현재 작업 브랜치를 푸시한다. main 병합·운영 배포·운영 DB 변경은 수행하지 않는다. 선행 작업의 운영 마이그레이션 4개와 적용 전후 보존 검증은 별도 대기 중이다. 자동 승인 검토가 운영 DB 테이블별 건수·비교용 해시의 임시 보관을 거절하여 사용자 승인 요청이 남아 있다. 이번 정책 답변과 브랜치 푸시 요청은 해당 데이터 보관 승인을 대신하지 않는다.
