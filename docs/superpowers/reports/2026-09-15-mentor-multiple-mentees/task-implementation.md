# 한 멘토의 복수 멘티 배정 개선 결과.

- 기존 DB는 멘티별 한 명의 멘토, 멘토별 여러 멘티를 지원한다. 스키마 변경은 필요하지 않았다.
- 프로그램의 멘티 여러 명을 체크한 뒤 같은 멘토에게 배정하도록 화면을 개선했다. 현재 담당 멘토와 개별 해제 기능을 함께 제공한다.
- 같은 멘토의 기존 배정은 다시 쓰지 않는다. 다른 멘토를 교체할 때는 확인하며 선택하지 않은 멘티의 배정은 유지한다.
- 각 배정은 기존 권한 검사를 사용하는 API로 처리한다. 일부 실패하면 성공한 배정은 유지하고 실패 항목만 다시 선택된 상태로 남긴다.
- 프로그램 매니저의 배정 탭도 프로젝트 대신 프로그램을 선택하므로 프로젝트가 없는 멘티에게 배정할 수 있다.

검증 결과.

- 관련 화면·API·권한 테스트 64개 통과.
- 전체 단위 테스트 154개 파일, 2,076개 통과.
- 격리된 로컬 PostgreSQL 통합 테스트 8개 파일, 62개 통과.
- 실제 DB에서 같은 멘토의 두 멘티 배정과 서로 다른 프로그램의 배정을 검증했다. 개별 교체·해제 후 다른 배정 보존, 미배정 프로젝트 접근 거절, 담당 매니저 범위를 확인했다.
- 실제 React 컴포넌트의 브라우저 검증에서 두 멘티 선택·배정과 미선택 멘티의 기존 담당 멘토 유지 확인.
- npm run lint 및 npm run build 통과.
- 운영 계정의 배정 데이터는 변경하지 않았다. 사용자가 선택하여 배정하는 화면만 배포한다.
