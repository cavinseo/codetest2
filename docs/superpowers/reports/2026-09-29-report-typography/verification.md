# 결과보고서 단계별 서식 적용 및 검증.

## 적용 내용.

- 장 제목 16pt·0mm, 절 제목 14pt·4mm, 소제목 12pt·8mm, 본문 11pt·12mm, 하위 항목 10pt·16mm를 적용했다. 본문 줄간격은 160%이고 그림 설명은 9pt다.
- 표지와 표·그림의 폭 및 내용은 유지했다. 미리보기와 Word가 같은 페이지 배치 결과를 사용한다.
- 점·원·사각형·대시·숫자 글머리를 인식한다. 기호 앞의 공백·탭은 하위 항목으로, (1) 형태는 소제목으로 표시한다. 긴 글머리는 다음 줄과 다음 페이지에서도 본문 시작선을 유지하며 기호를 반복하지 않는다.
- 원문과 저장 모델을 유지하고 같은 원문 블록을 교정한다. DB 구조 변경은 없다.
- 새 보고서 생성 시 상세 제품설명의 제목과 본문을 분리해 첫 글머리부터 일관된 서식을 적용한다.
- 현재 샘플 양식의 기존 저장 보고서에도 표시 서식이 적용된다. 표지 없는 구형 보고서는 기존 렌더러를 유지하고 새 미리보기 생성 시 현재 양식을 사용한다.

## 검증 결과.

- 전체 린트, 전체 타입 검사, 189개 파일의 2,839개 테스트, 프로덕션 빌드, Git diff 공백 검사가 통과했다.
- 다섯 단계, 글머리·탭 구분, 긴 문단 페이지 분할, 음수 오인식 방지, 원문 보존, 미리보기 교정 대상, Word 크기·들여쓰기·실제 탭 요소와 상세 설명의 첫 글머리를 검증했다.
- 타입 검사에서 테스트의 복합 filter 타입 축소 누락을 확인해 두 filter로 분리했고 관련 11개 테스트와 전체 타입 검사를 다시 통과했다.
- AI PLC 관리 장비의 저장 조회본에 계층형 멘토 분석·개요 설명을 테스트용으로 넣고 프로덕션 빌드를 Chrome에서 검증했다.
- 21쪽, WS-2 세부기술 41행, 고객요구사항 15개를 확인했다. 가로 잘림, 페이지 여백 초과, 브라우저 오류는 없었다.
- 원문 전체 교정, 표 셀 교정, 초안 저장·재열기, 완료본 열람, 이미지와 Word 다운로드가 통과했다.
- 브라우저 API는 테스트 응답으로 대체했으며 운영 DB 저장은 0회다. Word는 파일 생성·다운로드와 XML 구조까지 검증했으며 Word 앱의 실제 인쇄 렌더링은 확인하지 않았다.
