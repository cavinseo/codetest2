# 배정 멘토 편집과 워크시트 분석·결과보고서 연동 검수.

2026-09-11. 운영 배포 전 로컬 구현·검수 결과다.

권한 변경 커밋은 `5882ee8`, 분석·보고서 연동 커밋은 `2332ff7`이다.

## 요청과 확정 범위.

> 남은 작업을 진행하고 멘토에게 멘티의 프로젝트를 수정할 수 있도록 권한을 주어라.
>
> 배정받은 멘티의 프로젝트만 수정가능.

멘토의 유효 프로젝트 역할을 현재 소유 멘티의 배정에 따라 EDITOR로 결정한다. 멘토로 배정된 프로그램 매니저도 동일하다. 미배정·배정 해제된 멘토는 과거 ProjectMember OWNER/EDITOR/COACH 역할로 접근할 수 없다. 프로젝트 삭제, 소유권 이전, 회원 관리, 멘토 배정 권한을 추가하지 않는다. 팀원 초대 메뉴는 OWNER/ADMIN에만 표시한다.

## 구현.

- 개요 제품명·이미지·시장정의·목표 고객을 보고서 원본으로 연결했다. 개요 저장 시 빈 텍스트를 명시적으로 보관하여 이미지를 제거했을 때 과거 보고서 이미지가 부활하지 않게 했다.
- WS-2·3·4·12·13·15·16·17의 메인 탭과 개별 경로에 ‘멘토 분석(보고)’를 추가했다. 기존 공개 ‘멘토 의견’과 별도다.
- WS-12는 스펙 항목명과 설명을 저장한다. 최신 항목을 추가로 불러와도 기존 설명을 지우지 않는다. 원본에서 이름이 바뀌거나 삭제된 항목은 멘토가 직접 정리한다. 동일한 항목명은 중복 추가하지 않는다.
- WS-13은 개선 제품명/설명, WS-15는 핵심/보완 자산 분석을 각각 입력한다. 다른 대상 워크시트는 분석 본문을 입력한다.
- FinalReport.draft.worksheetAnalysis를 재사용했다. 분석만을 위한 DB 마이그레이션은 없다.
- report GET의 worksheetId 조회는 권한 없는 프로젝트 열람자에게 canEdit:false만 반환한다. report PATCH는 한 워크시트만 갱신하고 다른 분석·자유 입력·기존 문서·완료본을 보존한다.
- 프로젝트/멘토 배정 잠금과 보고서 버전 검사로 배정 변경 및 동시 저장을 처리한다. 충돌은 409, 합산 저장 용량 초과는 413으로 거절한다.
- 분석 변경 후 미리보기 재생성이 필요하다. 분석을 누락한 구버전 PUT도 원본을 삭제할 수 없으며 완료하려면 최신 분석을 포함해 다시 만들어야 한다.
- 분석을 포함한 보고서 초안은 현재 배정 멘토만 읽는다. 관리자·미배정 PM·멘티는 완료본만 읽는다. 완료본은 재완료 시 교체한다.
- 미배정 프로젝트 조회 실패 시 빈 OWNER 프로젝트를 만들던 화면 처리를 제거했다. 접근 거부 안내와 대시보드 링크를 표시한다.

## 환경과 검수 한계.

- DB는 로컬 127.0.0.1:55439의 overview_20260911만 사용했다. 통합 테스트는 고유 접두어 자료를 정리하고, 브라우저는 report_ui_* 모의 자료로 검수했다. 운영 회원·프로젝트·SMTP는 변경하지 않았다.
- WS-4/QFD 캡처는 최소 모의 자료로 실제 생성했다. 실사용자의 대용량 보고서와 모든 화면 크기를 재검수한 것은 아니다.
- 개요 신규 필드가 모두 null/undefined인 기존 자료에만 기존 보고서 자유입력을 사용한다. 새 개요를 저장하면 개요 전체를 원본으로 사용한다. 기존 자유입력 값과 완료본은 삭제하지 않는다.
- 브라우저 뒤로가기에도 입력 보호 대화상자를 구현했다. 다만 인앱 브라우저 자동화의 back 호출에서는 대화상자를 관찰하지 못했고 링크 이탈 확인은 CDP 입력 시간 초과로 끝났으므로 이 두 경로의 보호 동작은 통과로 판정하지 않았다. 검증된 것은 메인 탭 이동 취소와 저장 후 재조회다. 저장 전에는 ‘멘토 분석 저장’을 사용해야 하며 자동 저장 기능은 아니다.
