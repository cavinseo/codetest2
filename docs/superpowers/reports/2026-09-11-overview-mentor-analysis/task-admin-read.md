# 관리자 멘토 분석 초안 열람 추가.

2026-09-11 후속 요청 “관리자는 볼수 있도록 하라”를 반영했다. 앞선 검수 보고서의 관리자 비공개 판정 이후 적용한 정책 변경이다. 이 변경은 로컬 구현·검수 완료 상태이며 아직 푸시·운영 배포하지 않았다.

## 변경 범위.

- 관리자는 멘토 배정 유무와 관계없이 8개 워크시트의 분석 초안과 결과보고서 초안을 조회할 수 있다.
- API에서 조회 권한과 편집 권한을 분리했다. 기존 프로젝트 접근 검사를 먼저 통과해야 하며, 관리자에게 편집 권한을 부여하지 않는다.
- 워크시트 분석에 ‘관리자 열람 전용’ 안내를 표시한다. 텍스트 영역은 readOnly이며 저장·WS-12 항목 불러오기·추가·삭제 버튼은 숨긴다. 저장본 다시 불러오기와 결과보고서 링크는 제공한다.
- 결과보고서는 기존 읽기 전용 화면을 사용한다. 초안/완료본 전환과 문서 열람은 가능하며 수정·저장·완료는 배정 멘토만 가능하다.
- 멘티와 미배정 멘토·프로그램 매니저에게 초안을 반환하지 않는다. 서버의 PUT·POST·PATCH 작성 권한, 완료본 보존, 버전 충돌 처리와 DB 구조는 변경하지 않았다.

## 검수.

1. 관리자 조회 허용 테스트를 먼저 수정·추가하여 기존 코드에서 실패하는 것을 확인했다. 관리자에게 기존 코드가 `canEdit:false` 또는 완료본만 반환하여 요구한 초안을 읽을 수 없었다.
2. 서버 수정 후 API 테스트 94개가 통과했다. 8개 분석별 관리자 조회·쓰기 거절, 관리자 완료본 명시 조회, 멘티·미배정 계정 비공개를 검사한다.
3. 전체 테스트 140개 파일/1,874개가 통과했다. 한글 인코딩 검사와 전체 lint가 통과했으며 lint에는 기존 .stryker-tmp 경고 18개가 남아 있다.
4. 최종 `npm run build`가 통과했고 정적 페이지 35/35개를 생성했다.
5. 격리 DB `127.0.0.1:55439/overview_20260911`에서 final-report 통합 테스트 14개가 통과했다. 실제 세션의 관리자 열람 허용, 쓰기 차단, 멘티 비공개와 기존 완료본 유지가 포함된다.
6. 로컬 브라우저의 검수용 관리자 계정으로 8개 워크시트를 모두 열었다. 기존에 저장한 분석과 관리자 열람 전용 안내를 확인했으며 저장·추가·삭제 버튼은 없었다. WS-2 텍스트 영역의 readOnly 속성이 true였고 저장본 다시 불러오기가 동작했다.
7. 결과보고서에서 저장된 초안과 갱신 필요 안내가 표시되었으며 저장·완료 버튼은 없었다. 화면 검수 직후 브라우저 오류 로그는 없었다.

## 영향과 한계.

운영 DB의 회원·멘토 배정·프로젝트·분석 내용은 변경하지 않았다. DB 마이그레이션이 필요하지 않다. 운영 반영 전까지 기존 정식 서비스에서는 관리자의 초안 열람이 여전히 차단된다. 기존 미저장 멘토 입력의 브라우저 뒤로가기·링크 이탈 보호 검수 한계는 이번 읽기 전용 변경과 별도로 남아 있다.
