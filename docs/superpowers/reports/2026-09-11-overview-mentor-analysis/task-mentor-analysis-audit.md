# 멘토 전용 분석 작성 기능 재점검.

2026-09-11 사용자 요청에 따라 배포된 기능의 구현과 권한을 재점검했다. 기능 코드와 운영 데이터를 변경하지 않았다.

## 판정.

지정한 8개 워크시트의 입력·저장·결과보고서 연결을 코드와 테스트에서 확인했다. 현재 운영에서 확인한 두 프로젝트는 소유 멘티에게 멘토가 배정되지 않아 작성 기능이 표시되지 않는다. 관리자에게도 비공개 작성 영역을 표시하지 않는 것이 현재 구현된 정책이다.

| 대상 | 입력 내용 | 확인 결과 |
| --- | --- | --- |
| WS-2, WS-3, WS-4 | 워크시트별 분석 내용 | 입력 스키마·공통 화면·보고서 각 절 연결을 확인했다. |
| WS-12 | 최종 목표 스펙 항목명과 설명 | 항목 불러오기·기존 설명 보존·보고서 설명 표 연결을 확인했다. |
| WS-13 | 개선 제품(서비스)명과 설명 | 두 입력 필드와 보고서 개선 제품 정보 연결을 확인했다. |
| WS-15 | 핵심자산·보완자산 분석 | 분리 입력과 해당 자산 표 뒤 분석 연결을 확인했다. |
| WS-16, WS-17 | 워크시트별 분석 내용 | 자금 계획 표 뒤 분석 연결을 확인했다. |

## 직접 확인한 근거.

- `app/api/projects/[id]/report/route.ts:32`에서 MENTOR 또는 실제 멘토로 배정된 PROGRAM_MANAGER인지와 현재 프로젝트 소유 멘티의 mentorId를 모두 검사한다.
- 같은 파일 70행의 분석 조회는 비권한자에게 `canEdit:false`만 반환한다. 77행부터 보고서 전체 조회도 비권한자에게 완료본만 제공한다. 104행은 분석 저장·보고서 저장·완료를 403으로 차단한다.
- 저장 트랜잭션은 프로젝트와 배정 행을 잠그고 배정을 다시 확인한다. 다른 워크시트 분석과 완료본을 보존하며, 분석 수정 후 미리보기 갱신 전 완료를 거절한다.
- `components/project/MentorWorksheetAnalysis.tsx:119`는 권한이 없으면 폼을 숨긴다. 135행의 이름은 ‘멘토 분석(보고)’다. 기존 ‘멘토 의견’은 별도 공개 의견 기능이다.
- `app/project/[id]/page.tsx:935`와 `app/project/[id]/layout.tsx:18`에서 메인 탭 및 개별 워크시트 경로에 공통 분석 컴포넌트를 연결한다.
- `lib/final-report-document.ts:162`부터 지정한 워크시트 분석을 해당 보고서 위치에 연결한다. 분석 저장 후 보고서 미리보기를 다시 생성하고 완료해야 멘티에게 새 내용이 공개된다.

## 재실행 결과.

- 관련 4개 테스트 파일의 134개 테스트가 통과했다. 권한 차단, 8개 입력 형식, 분석 보존, 보고서 매핑, 공개본 유지 검사를 포함한다.
- 전체 `npm run test`를 다시 실행하여 140개 파일, 1,866개 테스트가 통과했다. 한글 인코딩 검사도 통과했다.
- 이번 점검에서는 기능 코드가 바뀌지 않아 타입 검사·lint·빌드·격리 DB 통합 테스트를 추가 재실행하지 않았다. 직전 실행 증거는 task-2.md에 있다.
- 정식 주소의 별도 검증 탭에서 admin 권한을 확인했다. ‘공장 시스템 관리 솔류션’의 WS-2에서 공개 ‘멘토 의견’은 표시되고 비공개 분석 폼은 표시되지 않았다. 결과보고서에는 완료본 대기 안내만 있었고 초안 작성·완료 버튼은 없었다. 해당 화면 확인 직후 브라우저 오류 로그는 없었다.
- Supabase 운영 DB를 읽기 전용으로 조회했다. `proj_d6e8fd6263894ca6`와 `proj_105223d729a94047` 모두 현재 소유 멘티의 멘토 배정이 없었다. 임의 배정·계정 변경·분석 저장은 하지 않았다.

## 사용 조건과 검수 한계.

관리자 또는 프로그램 매니저가 해당 멘티에게 멘토를 배정한 뒤, 그 멘토 계정으로 정식 서비스에 접속해야 한다. 해당 워크시트 하단 ‘멘토 분석(보고)’에서 작성하고 ‘멘토 분석 저장’을 누른다. 보고서에서 미리보기를 다시 만든 뒤 완료하면 멘티에게 공개된다.

이번 운영 검수에는 배정 멘토로 로그인해 실제 저장하는 경로가 포함되지 않았다. 이전 격리 로컬 브라우저에서 수행한 8개 분석 저장·완료본 유지 검수와 이번 재실행한 자동 테스트를 구분한다. 기존 미저장 입력의 뒤로가기·링크 이탈 보호에 대한 자동화 검수 한계도 task-2.md에 남아 있다.
