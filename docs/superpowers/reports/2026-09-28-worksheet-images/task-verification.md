# 워크시트 결과 그림 반영 및 다운로드 검증.

## 변경 범위.

- WS-4 적합도, WS-7 Kano 산점도, WS-9 QFD의 실제 결과를 보고서 그림 위치에 반영한다.
- ‘워크시트 그림 반영’은 기존 보고서 문구·표·보완 입력을 보존하고 그림만 교체한다.
- 각 워크시트 탭과 개별 페이지에 PNG 다운로드를 제공한다. 저장된 보고서의 그림도 내려받을 수 있다.
- WS-7 개별 페이지에 실제 그래프와 분석 집계표를 연결했다.
- 로딩 완료 대기, 조회 실패 차단, 넓은 표와 긴 입력값 펼치기, 밝은 배경 및 SVG 축 글자색 보정, 캡처 후 입력 요소·스타일·스크롤 복구를 적용했다.

## 검증 결과.

- 원본 작업 폴더에서 테스트 187개 파일, 2,814개 항목 및 린트 통과.
- 운영 기준 a7058eb에 이번 변경만 적용한 별도 작업 폴더에서 테스트 182개 파일, 2,785개 항목 및 린트·프로덕션 빌드 통과.
- 원본 폴더의 마지막 빌드는 코드·타입 검사 후 `.next/export`의 Windows EBUSY 잠금으로 종료되어 별도 폴더에서 최종 빌드를 검증했다.
- Chrome에서 보고서 그림 3장, PNG 다운로드 6건, 저장된 그림 다운로드, 초안 저장·재조회, 문구 유지, 읽기 전용 다운로드를 확인했다.
- 실제 캡처 바이트 3장이 DOCX 내부 이미지와 일치했다. 검증용 초안은 402,257바이트였다.
- QFD 마지막 열·목표값, 적합도 H/M·의견, Kano 축·점·계수를 PNG에서 직접 확인했다.
- 브라우저 API는 임시 데이터로 대체했다. 운영 데이터 쓰기 0건, 페이지 오류 0건.
