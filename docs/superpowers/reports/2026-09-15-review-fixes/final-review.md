## 독립 검증.

- 전체 단위 테스트 161파일 2,228건 통과, 로컬 DB 통합 10파일 91건 통과.
- npm run lint, TypeScript, npm run build 통과. 로컬 lint의 생성된 Stryker 임시 파일 경고는 오류 0건이며 배포 대상 소스가 아니다.
- CRAP 기준 초과 0건, 최대 29.5. 기존 실패 함수 project-creation-approval은 문장 19/19, CRAP 38.6에서 17.0으로 개선했다. 기준을 낮추지 않았다.
- 변경된 변이 대상 account-deletion 40/40, import-json-schema 16/16 모두 검출. 첫 실행의 오류 안내 문자열 생존을 추가 검증으로 해결했다. 전체 저장소 변이 점수와는 구분한다.
- 네트워크 보호 연결을 의도적으로 원복하면 MCP 생성·검증 테스트 2건이 실패하고 수정 복구 후 98건이 통과하는 역검증을 수행했다.
- 독립 리뷰에서 계정·네트워크 범위의 추가 차단 결함은 없었다. 보고서 비동기 목적지 문제는 추가 재현·수정·독립 재리뷰로 닫았다.
- 기존 동시 이관 테스트는 새 advisory lock 이후 실제 users FOR UPDATE를 기다리도록 동기화 지점만 보완했다. 기존 경합·자료 보존 단언은 유지했다.

## 범위와 보존.

운영 DB와 실회원으로 쓰기 테스트하지 않았고 Prisma 스키마·마이그레이션도 변경하지 않았다. 기존 작업 폴더의 테스트 되돌림은 패치로 백업 후 최신 커밋 내용으로 복구했다. 별도 과거 작업 폴더의 변경도 백업하고 검증 없이 합치지 않았다.

Navigation API 지원 Chromium에서 양방향 이력과 교정 보존을 확인했다. 미지원 브라우저 fallback은 입력을 보존하지만 앞으로가기 이력까지 보존하지 못할 수 있다. 운영 인증이 필요한 관리자 화면은 로컬 동등 환경과 실제 API 테스트로 검증했으며, 운영에서는 로그인 진입점과 배포 상태를 확인한다.
