# 후속 위험요소 작업 목록

- 공개 설문 제출의 빈 응답, 교차 프로젝트 요구사항, 동시 제출 중복을 차단한다.
- 취약한 Next.js, Nodemailer, Prisma 전이 의존성을 갱신하고 xlsx 파서를 안전한 대안으로 교체한다.
- Google Forms 가져오기의 시스템 사용자 FK, 중복 저장, 전역 토큰 접근 경계를 수정한다.
- 스펙 Excel 교체를 트랜잭션으로 보호하고 스펙 초기화의 서버·UI 불일치를 수정한다.
- 세션 만료·폐기, 비프로덕션 인증 우회, 로그인·가입·초대·설문 레이트리밋을 보완한다.
- 서비스 설정과 OAuth 토큰을 영속 비밀 저장소로 이전하고 보안 헤더·오류 응답을 강화한다.
- 과거 SQLite DB를 Git 이력과 원격 브랜치에서 제거하고 영향 자격 증명을 회전한다.
- Dropbox 동기화 경로 밖에서 프로덕션 빌드를 재검증한다.
