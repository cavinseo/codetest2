# Supervising Dual-AI Delivery

감리 AI(계획·검증)와 실행 AI(코딩)를 이중화해 운영할 때 쓰는 스킬. 핵심 원칙:
**완료 보고서는 주장이다. 판정은 감리자의 독립 재현으로만 한다.**

- `SKILL.md` — 발행 전 4대 의무, 완료 보고 판정 레시피 7단계, 합리화 금지 표, Red Flags
- `prompt-template.md` — 위임 프롬프트 10절 템플릿과 절별 존재 이유

FreshLink(농수산물 B2B 유통 플랫폼)와 codetest2 프로젝트의 실제 다단계 감리
사이클(검사→수정→배포, 계획서 기반 Task 위임)에서 베이스라인 관찰(RED) →
스킬 작성(GREEN) → 실전 판정 3회 이상으로 검증했다.
